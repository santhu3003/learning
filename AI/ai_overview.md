# Introduction to AI and Machine Learning

This documentation provides a beginner-friendly overview of Artificial Intelligence (AI), Machine Learning (ML), types of ML, and well-known algorithms. Simple examples are included for clarity.

---

## 🤖 What is Artificial Intelligence (AI)?

**Artificial Intelligence (AI)** refers to the ability of machines or software to perform tasks that normally require human intelligence.  
These tasks include understanding language, recognizing images, making decisions, and solving problems.

**Examples of AI in everyday life:**
- Virtual assistants (like voice-controlled smart speakers)
- Recommendation systems (YouTube, Netflix)
- Face unlock on smartphones

---

## 🧠 What is Machine Learning (ML)?

**Machine Learning (ML)** is a subset of AI that focuses on teaching machines to learn patterns from data instead of being explicitly programmed.

**Simple Example:**  
Imagine you want a computer to recognize pictures of cats.  
Instead of writing rules like "cats have pointy ears," you give the computer thousands of cat images and let it learn the patterns on its own.

---

## 📚 Types of Machine Learning

Machine Learning is generally divided into three major types:

### 1. Supervised Learning

- **Definition:** The model is trained using labeled data (each input has a correct output).
- **Example:**  
  Input: "Hours studied" → Output: "Exam score"  
  The model learns the relationship and can predict a student's score based on study hours.

**Common Algorithms & Use Cases:**
- **Linear Regression:** Predicting continuous values (house prices, sales forecasts)
- **Logistic Regression:** Classifying binary outcomes (spam detection)
- **Decision Trees:** Rule-based predictions (medical diagnosis, customer segmentation)
- **Random Forest:** Combines many decision trees for accuracy (fraud detection, risk assessment)
- **Support Vector Machines (SVM):** Classifies complex data (handwriting, image classification)
- **k-Nearest Neighbors (kNN):** Classifies based on similarity (recommendation systems, pattern recognition)

---

### 2. Unsupervised Learning

- **Definition:** The data has no labels; the model finds patterns or groups on its own.
- **Example:**  
  An algorithm groups customers with similar buying behavior from purchase data.

**Common Algorithms & Use Cases:**
- **k-Means Clustering:** Groups similar items (customer segmentation, image compression)
- **Hierarchical Clustering:** Creates tree-like clusters (genetic research, document grouping)
- **Principal Component Analysis (PCA):** Reduces features while keeping important info (data visualization, speeding up ML models)

---

### 3. Reinforcement Learning

- **Definition:** An "agent" learns by receiving rewards or penalties for its actions.
- **Example:**  
  A game bot learns to play by trying actions and getting rewarded for winning, penalized for losing.

**Common Algorithms & Use Cases:**
- **Q-Learning:** Learns optimal actions in defined environments (robotics, simple game agents)
- **Deep Q-Networks (DQN):** Combines Q-Learning with deep learning (video games)
- **Policy Gradient Methods:** Optimizes behavior directly (robotics control, autonomous driving, advanced game AI)
